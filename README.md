# COM7 Job Vacancy — เว็บแอปค้นหาตำแหน่งงานว่าง

เว็บแอป Google Apps Script สำหรับค้นหาตำแหน่งงานว่างของ COM7 และบริษัทในเครือ (BaNANA, Studio7, True Shop, dtac ฯลฯ) ตามจังหวัด พร้อมหน้า **Admin** สำหรับ

- เปลี่ยนแหล่งข้อมูลตำแหน่งงาน (ลิงก์ Google Sheet) โดยไม่ต้องแก้โค้ด
- ส่งอีเมลยืนยัน/แจ้งเตือนให้ผู้สมัครงานเป็นชุด พร้อมดูตัวอย่างอีเมลก่อนส่งจริง (หน้าตาตรงกับที่ส่งจริงเป๊ะๆ)

## โครงสร้างโปรเจกต์

```
com7-Job-Vacacy/
├── gas/                          ← ซอร์สโค้ดจริง (แก้ไขไฟล์ที่นี่เท่านั้น)
│   ├── server/                   ← ฝั่ง Server (รันบน Google, เข้าถึง Sheet/Cache/Properties ได้)
│   │   ├── Router.js             ← routing (doGet) เลือกแสดงหน้า Index หรือ Admin + ส่ง config ให้ client
│   │   ├── Config.js             ← ค่าคงที่ทั้งหมดของระบบ (ลิงก์ CSV เริ่มต้น, ชื่อคอลัมน์, ข้อความอีเมล ฯลฯ)
│   │   ├── VacancyData.js        ← ดึง/แปลงข้อมูลตำแหน่งงานจาก Google Sheet (CSV)
│   │   ├── CacheUtils.js         ← เก็บ/อ่าน cache ข้อมูลตำแหน่งงาน (ลด quota การโหลดชีทซ้ำ)
│   │   ├── AdminAuth.js          ← ตรวจ/เปลี่ยนรหัสผ่านแอดมิน
│   │   ├── AdminSheetConfig.js   ← บันทึก/รีเซ็ตลิงก์ Google Sheet ที่ใช้ดึงข้อมูลตำแหน่งงาน + แปลงลิงก์เป็น CSV
│   │   ├── EmailSheetConfig.js   ← บันทึก/รีเซ็ตลิงก์ชีทฐานข้อมูลผู้สมัคร (สำหรับส่งอีเมล)
│   │   ├── EmailCandidates.js    ← ดึงรายชื่อผู้สมัครจากชีท + อัปเดตสถานะส่งอีเมลแล้ว/ยังไม่ส่ง
│   │   ├── EmailTemplate.js      ← สร้าง HTML อีเมล (ใช้ร่วมกันทั้งตอน "ดูตัวอย่าง" และตอนส่งจริง)
│   │   ├── EmailSender.js        ← ส่งอีเมลจริง (Brevo API หรือ Gmail สำรอง) + log ผลการส่ง
│   │   ├── EmailSettings.js      ← บันทึก/อ่านค่า Brevo API Key ที่ Script Properties
│   │   └── EmailImages.js        ← อัปโหลดรูปแนบอีเมล (เช่น รายละเอียดวันสัมภาษณ์) ขึ้น Google Drive
│   ├── client/                   ← ฝั่ง Client (HTML/CSS/JS ที่รันในเบราว์เซอร์ผู้ใช้)
│   │   ├── Index.html            ← หน้าค้นหาตำแหน่งงาน (หน้าหลักที่ผู้สมัครงานเห็น)
│   │   └── Admin.html            ← หน้าแอดมิน: จัดการลิงก์ฐานข้อมูล + ส่งอีเมลยืนยัน
│   └── appsscript.json           ← manifest ของ Apps Script (ต้องอยู่ root ของโปรเจกต์ที่ push)
├── dist/                         ← ไฟล์ที่ build แล้ว (สร้างอัตโนมัติ, ไม่ขึ้น Git, ใช้ push ขึ้น Apps Script)
├── build.js                      ← สคริปต์คัดลอก gas/ → dist/ (คงโครงสร้าง server/client ไว้เหมือนเดิม)
├── .clasp.json                   ← ตั้งค่า clasp ให้ rootDir ชี้ไปที่ dist/ (ไม่ขึ้น Git เช่นกัน เพราะมี scriptId)
├── .gitignore                    ← กัน node_modules, dist, .clasp.json ไม่ให้ขึ้น Git
└── .vscode/settings.json         ← ซ่อน node_modules ออกจากช่องค้นหา แต่ยังคงแสดง/ค้นหาไฟล์ใน gas/ ได้ปกติ
```

**หลักการ:** `gas/` คือ source of truth ที่แก้ไขและ commit ขึ้น Git ตามปกติ แบ่งชัดเจนเป็น
`server/` (โค้ดที่รันบนเซิร์ฟเวอร์ Google เท่านั้น) กับ `client/` (โค้ดที่ส่งไปรันในเบราว์เซอร์ผู้ใช้)
ส่วน `dist/` เป็นแค่ output ที่ build script สร้างขึ้นมาก่อน push ขึ้น Apps Script เท่านั้น
จึงไม่ควร (และถูกกันไว้ด้วย `.gitignore` ไม่ให้) commit `dist/` ขึ้น Git

> หมายเหตุ: Apps Script อ้างอิงไฟล์ HTML ด้วยชื่อ path แบบไม่มีนามสกุล เมื่อไฟล์อยู่ในโฟลเดอร์ย่อย
> เช่น `client/Index.html` จะถูกเรียกใช้ในโค้ดด้วย `HtmlService.createHtmlOutputFromFile('client/Index')`
> (ดูตัวอย่างใน `gas/server/Router.js` ฟังก์ชัน `doGet`)

## วิธีใช้งาน (ครั้งแรก)

1. ติดตั้ง dependencies:
   ```
   npm install
   ```
2. ตั้งค่า `.clasp.json` ใส่ `scriptId` ของ Apps Script project จริง (ไฟล์นี้ไม่ขึ้น Git ให้ใครก็ตั้งของตัวเอง)
3. Login clasp (ครั้งแรกเท่านั้น):
   ```
   npx clasp login
   ```
4. Build และ deploy:
   ```
   npm run deploy
   ```

## คำสั่งที่ใช้บ่อย

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run build` | คัดลอก `gas/` → `dist/` อย่างเดียว ไม่ push |
| `npm run deploy` | build แล้ว push ขึ้น Apps Script ทันที |
| `npm run dev` | เฝ้าดูการแก้ไขใน `gas/` แล้ว build+push ให้อัตโนมัติทุกครั้งที่เซฟ |
| `npm run push` | push แบบ force (ไม่ build ใหม่) |
| `npm run open` | เปิดโปรเจกต์ใน Apps Script editor บนเว็บ |

## หน้าค้นหาตำแหน่งงาน (`Index.html`)

- ผู้สมัครงานพิมพ์ชื่อจังหวัดเพื่อค้นหาตำแหน่งงานว่าง (ดึงข้อมูลจาก Google Sheet ที่ตั้งไว้ในหน้า Admin)
- กรองผลลัพธ์ซ้ำได้ตาม BU (BaNANA, Studio7, True Shop, dtac ฯลฯ) ด้วยแถบชิปสี — แถบนี้มีพื้นการ์ดสีขาวของตัวเองเพื่อให้อ่านง่ายเสมอ ไม่ว่าพื้นหลังจะเป็นรูปภาพแบบไหนก็ตาม
- ปุ่ม **"สนใจสมัครงาน"** บนการ์ดแต่ละตำแหน่ง เด้งไปยังฟอร์มสมัครงาน (ลิงก์ตั้งค่าอยู่ที่ `APPLY_FORM_URL` ใน `gas/server/Config.js` ปัจจุบันชี้ไปที่ `https://forms.gle/Y3RERjgbvKhzZnba6`)
- ปุ่ม **"สอบถามเพิ่มเติม"** ที่ท้ายหน้า เด้งไปยัง LINE OA (ลิงก์ตั้งค่าอยู่ที่ `LINE_CONTACT_URL` ใน `Config.js`)
- รูปพื้นหลังของหน้า (แบนเนอร์ช่วงบน) แก้ไขได้ที่ CSS `body::before` ใน `Index.html`

หากต้องการเปลี่ยนลิงก์ฟอร์มสมัครงานหรือลิงก์ LINE ให้แก้ค่าคงที่ใน `Config.js` แล้ว deploy ใหม่

## หน้า Admin (`?page=admin`)

เปิดเว็บแอปแล้วต่อท้าย URL ด้วย `?page=admin` เช่น
`https://script.google.com/macros/s/XXXXXXXX/exec?page=admin`

- รหัสผ่านเริ่มต้น: `com7admin` (**ควรเข้าไปเปลี่ยนทันทีหลัง deploy ครั้งแรก** ในหัวข้อ "เปลี่ยนรหัสผ่านแอดมิน")

### แท็บ ฐานข้อมูลตำแหน่งงาน

- วางลิงก์ Google Sheet แบบปกติ (ลิงก์แชร์/edit) บรรทัดละ 1 ลิงก์ ระบบจะแปลงเป็นลิงก์ CSV export ให้อัตโนมัติ
- กด "แปลงเป็น CSV (ดูตัวอย่าง)" เพื่อตรวจสอบก่อน แล้วค่อยกด "บันทึกลิงก์ใหม่"
- ข้อมูลที่บันทึกจะถูกเก็บไว้ใน Script Properties (ไม่ต้องแก้โค้ด ไม่ต้อง deploy ใหม่)
- มีปุ่ม "รีเซ็ตกลับเป็นค่าเริ่มต้นในโค้ด" หากตั้งค่าผิดแล้วอยากย้อนกลับ

### แท็บ ส่งอีเมลยืนยัน

- ดึงรายชื่อผู้สมัครจากชีทฐานข้อมูล (ตั้งลิงก์ได้เช่นเดียวกับฐานข้อมูลตำแหน่งงาน) พร้อมกรองตามสถานะ "ส่งแล้ว/ยังไม่ส่ง"
- เลือกผู้รับเป็นชุด (เช่น เลือก 50/100 คนแรกที่ยังไม่ส่ง) แล้วกด **"ส่งอีเมลให้ผู้ที่เลือก"**
- หัวข้อ/เนื้อหาอีเมลตั้งไว้ในโค้ด (`EMAIL_SUBJECT`, `EMAIL_BODY_TEMPLATE` ใน `Config.js`) ใช้ `{ชื่อ}` แทนชื่อผู้รับแต่ละคนอัตโนมัติ แอดมินอัปโหลดได้แค่รูปแนบ (เช่น รายละเอียดวันสัมภาษณ์)
- ปุ่ม **"ดูตัวอย่างก่อนส่ง"** เปิดหน้าต่างแสดงอีเมลตัวอย่างที่ render จาก template เดียวกันกับตอนส่งจริง (`EmailTemplate.js` ฟังก์ชัน `buildEmailHtml_`) จึงรับประกันว่าตัวอย่างกับอีเมลที่ส่งออกไปหน้าตาตรงกันเป๊ะ
- ระบบส่งผ่าน **Brevo API** เป็นหลัก (ตั้งค่า API Key ได้ที่ "ตั้งค่าผู้ส่งอีเมล (Brevo)" ในหน้า Admin ค่าจะถูกเก็บไว้ใน Script Properties เท่านั้น ไม่โผล่ในโค้ด) ถ้ายังไม่ตั้งค่า ระบบจะส่งผ่าน Gmail สำรองให้อัตโนมัติ (มีโควตาจำกัดรายวัน)
- ส่งสำเร็จแล้วระบบจะอัปเดตสถานะกลับไปที่ชีทต้นทาง และบันทึก log ไว้อีกแท็บหนึ่งในสเปรดชีทเดียวกัน

## Favicon

ไอคอนหน้าเว็บใช้ลิงก์รูปโลโก้ COM7 จาก Google Drive (ตั้งค่าไว้ใน `gas/server/Router.js` ตัวแปร `faviconUrl` และใน `<head>` ของ `Index.html` / `Admin.html`)

> หมายเหตุ: เว็บแอป Apps Script ที่รันบนโดเมน `script.google.com` เบราว์เซอร์บางตัวอาจยังใช้ favicon ของ Google แสดงที่แท็บแทน เนื่องจากเป็นข้อจำกัดของแพลตฟอร์ม ไม่ใช่จากโค้ดของเรา
